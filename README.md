# Shunsuke Yoneda Portfolio

GitHub Pages向けの静的ポートフォリオです。フレームワークやビルド作業は不要です。

## 公開方法

1. GitHubで `yoneda314.github.io` というPublicリポジトリを作成します。
2. このフォルダ内の `index.html` と `style.css` をリポジトリ直下へ置きます。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** のSourceを `Deploy from a branch` に設定します。
5. Branchで `main` と `/(root)` を選び、Saveします。

公開URLは `https://yoneda314.github.io/` です。

## 編集ポイント

- 本文・研究実績：`index.html`
- 色・レイアウト：`style.css` 冒頭のCSS変数
- メールアドレスは現在掲載していません。公開する場合は、フッター付近に追加してください。
